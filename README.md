# CODSOFT Data Analytics Internship - Runnable Tasks

This package contains all 5 tasks described in the CodSoft Data Analytics internship brief.

## Tasks
1. Data Cleaning & Preprocessing
2. Exploratory Data Analysis (EDA)
3. Data Visualization Dashboard
4. Customer Data Analysis
5. Web Data Extraction & Analysis

## How to run
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Run each task from its folder, one at a time:
   - `python task1_data_cleaning.py`
   - `python task2_eda.py`
   - `python task3_visualization.py`
   - `python task4_customer_analysis.py`
   - `python task5_web_scraping.py`

Each task creates an `outputs` folder automatically.

## Notes
- Tasks 1-4 use the included sample customer-sales CSV.
- Task 5 uses the public demo website `https://books.toscrape.com/`.
- Task 5 needs an active internet connection.
- The code is intentionally written in a beginner-friendly style and includes comments.
